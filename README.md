## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта парусной школы и яхт-клуба "Парус" на Клязьминском водохранилище. Сайт учебный, школа и её данные вымышленные.

Страницы:

- `index.html` - главная: о школе, популярные курсы, ближайшие выходы, отзывы, быстрая заявка в модальном окне;
- `courses.html` - каталог курсов с поиском и фильтрами, тест "какой курс мне подходит";
- `course.html` - страница курса: программа по занятиям, таблица цен, инструкторы;
- `fleet.html` - флот клуба, характеристики яхт, аренда с капитаном и без, сравнение яхт;
- `schedule.html` - расписание выходов и регат на месяц с фильтром по типу;
- `order.html` - заявка на курс, выход или аренду, способ оплаты, калькулятор стоимости;
- `account.html` - личный кабинет: вход, регистрация, заявки, статус по номеру, мои записи;
- `contacts.html` - контакты, карта Яндекса, вопрос инструктору, частые вопросы.
