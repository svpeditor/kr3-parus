## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта парусной школы и яхт-клуба "Парус" на Клязьминском водохранилище. Сайт учебный, школа и её данные вымышленные.

Страницы:

- `index.html` - главная: о школе, популярные курсы, ближайшие выходы, отзывы, быстрая заявка в модальном окне;
- `courses.html` - каталог курсов с поиском и фильтрами, тест "какой курс мне подходит";
- `course.html` - страница курса: программа по занятиям, таблица цен, инструкторы;
- `fleet.html` - флот клуба, характеристики яхт, аренда с капитаном и без, сравнение яхт;
- `schedule.html` - расписание выходов и регат на месяц с фильтром по типу;
- `order.html` - заявка на курс, выход или аренду, способ оплаты, калькулятор стоимости;
- `account.html` - личный кабинет: вход, регистрация, заявки, статус по номеру, мои записи;
- `contacts.html` - контакты, карта Яндекса, вопрос инструктору, частые вопросы.

## Lighthouse

Проверены страницы:

- `index.html`;
- `courses.html`;
- `order.html`.

Отчёт сохранён в папке `lighthouse/`.

Первая проверка (категория Accessibility, мобильный режим): `index.html` 94, `courses.html` 95, `order.html` 95. Остальные страницы проверены тем же способом: `course.html` 94, `fleet.html` 95, `schedule.html` 95, `account.html` 96, `contacts.html` 94. На всех страницах Lighthouse нашёл одну проблему: недостаточный контраст серого текста. Скриншот первой проверки: `lighthouse/first-check-index.png`.

После исправлений все восемь страниц получили 100. Отчёты: `lighthouse/accessibility-report.png` (главная), `lighthouse/accessibility-report-courses.png`, `lighthouse/accessibility-report-order.png` и те же отчёты в HTML.

Lighthouse проверяет не всё, поэтому страницы дополнительно проверены вручную: переход по Tab, работа меню и модального окна с клавиатуры, порядок заголовков, вид на разных ширинах.

## Исправления доступности

- серый текст (подписи категорий, подсказки к полям, авторы отзывов, строка в подвале) имел контраст 4.47:1 на белом и 4.1:1 на сером фоне, нужно не меньше 4.5:1; цвет `--color-muted` заменён с `#777777` на `#595959`, теперь контраст 7.0:1 и 6.4:1;
- в начало каждой страницы добавлена ссылка "Перейти к основному содержимому", она появляется при нажатии Tab, у `main` добавлен `id="main"`;
- видимый фокус задан для всех интерактивных элементов через `:focus-visible`, рамка 3px с отступом;
- у основного меню добавлен `aria-label`, у текущего пункта `aria-current="page"`;
- у кнопки "Меню" и кнопки "Поиск и фильтры" есть `aria-expanded`, меню закрывается клавишей Escape, и фокус возвращается на кнопку;
- у обязательных полей добавлена звёздочка и пояснение над формой, звёздочка скрыта от программ чтения с экрана через `aria-hidden`;
- подсказки и места для сообщений об ошибках связаны с полями через `aria-describedby`, у полей добавлены `autocomplete`;
- у ячеек-заголовков таблиц добавлен `scope`;
- обёртки широких таблиц получили `tabindex="0"`, `role="region"` и подпись через `aria-labelledby`, чтобы таблицу можно было прокрутить с клавиатуры;
- проверено, что на каждой странице один `h1`, заголовки идут по порядку, у всех `label` совпадает `for` и `id`, у всех изображений есть `alt`;
- модальное окно сделано на `<dialog>`: у него есть заголовок через `aria-labelledby`, кнопка закрытия с `aria-label`, при открытии фокус переходит в первое поле, закрывается кнопкой, Escape и щелчком по затемнению.
